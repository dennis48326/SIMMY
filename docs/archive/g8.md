New dev aids
- SIMMY_SHADER_TRACE=1: multi-state shader loads (kind, blend time, state -> shader list) and every
  state change ("[shader] ...").
- SIMMY_SHADER_STATES=0: multi-state shaders stay in their default state (the behaviour before this
  session), for before/after comparisons.
- SIMMY_FIXED_DT=1 (e_engine.cpp): every frame is one retrace of game time (repeatable runs; Apt still
  animates on the wall clock).
- SIMMY_FRAMES_FROM_HOUSE=1 (pc_main.cpp): --screenshot, --frames, SIMMY_SHOTS and
  SIMMY_GFX_LOWRES_UNTIL count from the first presented frame with a house loaded.
- SIMMY_GFX_HIRES_SHOTS=1 (pc_settings.cpp): render at 480 lines except the 3 frames before each
  SIMMY_SHOTS / --screenshot frame (a resize each time), so a long 1080p test costs about as much as a
  480-line one. SIMMY_GFX_LOWRES_SCALE=<f> (default 1): the scale those low-res frames use (0.5 makes
  the front end's 3D world map much cheaper with MSAA 4). hd.sh: HIRES_SHOTS=1 uses it.
