## 1. HUD d-pad icons gone after quit + re-enter (fixed: teardown, not fade)
Cause: the aux layer's 48 movie levels (gLevelInfo, aptauxpceorgl.cpp) and 350 texture slots were never
given back: every loadMovie (each dialog, screen, HUD icon swf) took a new level, so after the front end,
CAS, one game and the quit, the second HUD's swfs (d-pad icons "MOD_dpad_*_swf", motive icons...) found no
free level and silently did not load ("[apt] no free movie level for X" is now printed).
GC frees a movie when its last AptSharedPtr goes (AptCharacterAnimation release -> freeAnimation), and
AptLinker::Load (802A040C) shares a movie that is already loaded (AptLoader::IsLoaded).
Fix (src/libaptz/apt.cpp, aptvalue.cpp, aptplayer.cpp; src/game/aptauxpceorgl.cpp):
- AptGC::ForEachLive; after every CleanUnreachable, AptReleaseUnusedFiles frees each AptFile whose image no
  live CIH / script function / queued action uses: freeTexture per bitmap slot, freeRenderingUnit,
  freeSound, const strings unrooted, the image deleted, freeAnimation(levelInfo).
- AptAuxPCEorGL_FreeAnimation (800097C4: deletes the FlashBigFile, clears the level) and
  FreeConstantTable (800097C0) ported and installed in gAptFuncs. A failed load gives its level back.
- AptUpdate collects after 4 movie loads too (gAptLoadsSinceCollect), not only after 20000 allocations.
- AptLoadAnimation shares a loaded movie (same name, state 4) into a clip target (no second level)
  while a non-removed clip still shows it (IsShown); PC calls handleSWFLoadComplete for it as for a
  load. Needed for split screen + WAF (> 48 swfs). Sharing a movie whose clips had gone broke the pause
  tab bar ("undefined method addOption": its #initclip did not run again), hence the IsShown rule.
- freeTexture (aux) unbinds the texture from ENgcRenderer::m_textures first: SetTexture Unlock()s the
  previous stage texture, which crashed (SIGSEGV in ENgcRenderer::SetTexture from EIStaticSubModel::Draw)
  after R2L -> pause -> WXF -> pause.
- Regression runs: s14/shots/hl5.log, hl7.log, hl8.log (headless: pause submenus round trips, quit,
  re-enter), shots/back1.png (R2L, WXF, back to the game, motives panel).
Shots: shots/re3.png (4700, icons back after re-entry), shots/re4.png (re-entry + skills panel).
Note: "§0" money in all current shots (first and second game) comes from SimulatorFunds (main's
simulator), not from the HUD: worth telling the simulator side (s13 showed §20,000 with the stub).
