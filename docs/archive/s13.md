## 2. SWF6 interpreter ops (AptGetSwfVersion is always 6 on GC) - src/libaptz
- AptVar::IsNaNLike / IsNumericString (aptvalue.cpp): Apt's inlined numeric-string test; undefined is a number
  in SWF6; booleans, null, objects and non-numeric strings are NaN.
- Equals2: null is turned into undefined first (Apt null type 0x13); non-primitive operands equal only with the
  same type (undefined==undefined/null, objects by identity); bool vs any: toInteger; number vs non-numeric
  string: text compare; int vs float-like: within 0.001.
- StrictEquals: null->undefined too; numbers within 0.001 unless both int; strings case-insensitive (strcasecmp).
- LessThan2: strcmp for two strings; NaN-like operand -> undefined; ints unless a float.
- Greater: never undefined in SWF6; ints unless a float.
- ToNumber: NaN-like -> undefined; else int, or float when the string form has '.'.
- Add2: integer when either side is int and neither float. Old Add/Sub/Mul: int only for int+int.
- Divide/Modulo by 0 -> undefined; Modulo is fmodf. Old Equals within 0.001.
- isNaN(): no arg true, numbers false, undefined false. Boolean(): no arg undefined.
- Regression found while bisecting: treating undefined==null as false broke the main menu (fixed by the null
  rule above). Front end, CAS, live mode, pause, O2T, save, quit all re-tested.
