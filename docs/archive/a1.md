- `a1/hl.sh FRAMES NAME [ENV=..]` (headless), `a1/shot.sh FRAME NAME [ENV=..]` (offscreen + screenshot). SEQ=...
  overrides the pad sequence (default "start,a,right,a,up,a,a,left,a,house" -> live mode), DATA=... the data
  root, ARGS=... extra simmy arguments. XDG_DATA_HOME=$S/xdga1, run dir $S/a1/run, logs/wavs in $S/a1/shots.

## 1. Survey (GC architecture)

### Layers (bottom up)
1. **AX/MIX/AI (SDK)** -> PC: `src/platform/pc_audio.cpp` (SDL3 stereo mixer, 48 kHz, DSP-ADPCM decode, buses,
   `SIMMY_AUDIO_WAV` recorder). Earlier session.
2. **Engine platform audio** (`engine/e_ngcaudio.cpp` ENgcAudio = `_pActualAudio`, `e_ngcsamplestream.cpp`
   ENgcSFXStreamer 62 voices, `e_ngcstream.cpp` ENGCAudioStreamer 2 music slots): ported earlier.
   EAudio vtable (offsets the game uses): 0x40 PlayMusic, 0x48 StopMusic, 0x50 Pause/0x58 ResumeMusic,
   0x60/0x68 Set/GetMusicVolume, 0x70 SetMusicPan, 0x80 IsPlayingMusic, 0x88 AudioAllocVoice, 0x90 FreeVoice,
   0x98 AudioBindVoice, 0xA0 UnbindVoice, 0xA8/0xB0 Get/SetVoiceState, 0x28 Flush.
3. **Resources**: `samples` (ENgcAudioSampleManager, ERSampledata: 0x60-byte DSP header + frames, stereo = 2nd
   header at size/2), `audiostreams` (EAudioStreamManager, ERAudioStream: position only), `soundevents`
   (ESoundEventManager, ERSoundEvent 'SEVT'), `soundtrackdatas` (ESoundTrackDataManager, ERSoundTrackData
   'STRD' = a tiny sound VM program), `ambientscores` (EAmbientScoreManager, ERAmbientScore).
4. **Game sound director "BoxX"** (game/boxx.cpp, gamesound.cpp, gzsndsys.cpp, patch.cpp, audioinfo.cpp):
   - `cSoundPlayer` (Globs::pSound, 0x20 bytes): the game's API. PlayBySource(event id|name|ERSoundEvent*,
     source object id) queues {source, event id, time} (AddRefAsync of the event); Update plays queued events
     whose resource has loaded (cBoxX::MappedEvent), then cBoxX::UpdateGameMode and, unless paused, the
     BoxX update (vtable 0x14) and cGZSndSys::Update. SetGameMode/EnableSound/QuietAll/Pause*/volume setters
     are cBoxX::Event messages.
   - `cBoxX` (g_pBoxX, 0x7C): Event(msg, param, source, ERSoundEvent*, time) dispatcher: 1 play, 0x1E kill
     the source's sounds then play, 0x17 kill source, 0x13 stop music, 0x14 quiet all, 0x15/0x16 pause/
     unpause, 0x22 enable, 0x24 game mode, 0x25 SFX vol (group 1 + ambient), 0x26 music vol (group 2 +
     EAudio), 0x27 VOX vol (group 3), 0x2B old FX vol, 0x2C ambient vol, 0x28..0x2A/0x2D getters, 0x2F..0x34
     pause/unpause ambient/SFX/music. Keeps a multimap ERSoundEvent* -> source id ("sndob instances") and
     re-pans/attenuates every instance each frame in live mode from the listeners: **one listener per player
     camera** (_gd.m_players[0..1].m_cam, ESimsCam eye +0x418 / target +0x43C; GetListenerPosAndDir puts the
     ear g_cam_dist=2 along the view and g_cam_height=2 below the eye). Volumes of all listeners are summed
     (surround L/R/F/B, 0x400 = full) then converted to volume+pan, so in split screen a sound is heard by
     whichever player's camera is close (GC behaviour; the mix is one stereo output). Range from the event
     (+0x1F min, +0x20 max, /4 tiles), ducking by g_social_duck (0.45) when that player is in social mode.
   - `cSoundModeManager` (cBoxX +0x30): game modes 1 live, 2 front end, 3 loading, 4 CAS, 5 silent (disc
     error), 6 build/buy (paused live). Per frame: music volume from OptionsRecon +0x1D (fades), SFX/VOX/
     ambient volumes from +0x1C/+0x28/+0x29, the loading-screen loop sample ("load_loop%d"), and starts music:
     mode 2 front-end track s_frontEndTracks[0] = music_48_title_track; mode 4 CAS and 6 build/buy cycle
     music_24_bbcas1..3; mode 1 only the demo music.
   - `cHitMan` (g_pHitMan): the sound VM's scheduler: control groups (1 SFX, 2 music, 3 VOX; volume 0..0x400),
     update list of running cTracks, a 1-tick-per-frame timer, ducking map, sequence groups, and `cSoundCache`
     (64 cTrack slots, one per ERSoundEvent).
   - `cTrack` (0x98): runs the event's ERSoundTrackData program (32-bit instructions: opcode, reg A, B, C /
     imm16; registers 1..8 general (r1 source, r2 volume, r3 pan), 9 volume, 10 pan, 11 patch (setting it
     makes the sample channel), 12..16 fade, 17 duck priority). On disc there are only 3 programs:
     "playfromhitlist" (SFX), "playvox" (Simlish VOX), "playhitpatch" (music: sequence group 1, random patch).
   - `cSamplePatch`/`cSampleChannel`: a hit patch {stream id, sample id}: sample id != 0 -> cGZSndSys::
     CreateSoundEffect (a cGZSnd), else CreateAudioStream (a cGZMusic) of the stream id.
   - `cGZSndSys` (_gzSndSys = g_pSndSys): sample cache (cSoundCacheItem, 256 buckets, async loads, max 4 in
     flight), fades, the one music stream at a time (cGZMusic through EAudio::PlayMusic, fade to 0 on stop).
   - `cGZSnd`: a sample voice through EAudio voices (AudioAllocVoice/BindVoice/SetVoiceState; volume 0..0x400,
     pan 0..0x400 -> L/R gains).
   - `cAudioInfo`: object position (ObjectModule vt 0x94 -> object location / 16) and object data for the VM
     (source parameter requests: person motives etc.).
   - `AmbientScorePlayer`/`AmbientSoundPlayer` (game/ambientscoreplayer.cpp, ambientsoundplayer.cpp): the
     neighbourhood's ambient score "score%d" (house number), ERAmbientScore lists of ambient sound events.
5. **UI sounds**: `UIAUDIO` (game/uiaudio.cpp, 5 round-robin voices; samples played directly through EAudio
   voices, not BoxX). Ported earlier. Two ways in: C++ `UIAUDIO::PlaySound(sample id)` from targets (menu
   navigation, action menu, build/buy...) and the Flash movies' `setVariable("audio:NAME", ...)` handled by
   **UIAUDIOTarget** (game/uisupport.cpp: the text between the first and second ':' -> UIAUDIO::GetSound(name)
   -> PlaySound). Each target installs its names (MMU_UI_BROWSE_SAMPLE, PAZ_SndBrowse, CAS_OPEN, ...).
6. **Callers**: SAnimator2::eventHandler (sim animation notes: type 7 sound -> PlayBySource(note text, person
   id); type 1 footsteps -> "footstep_<surface>_<shoe>_<step>"), ISimsObjectModel::animEventHandler (object
   animation note type 5 -> PlayBySource(text, object id)), the behaviour primitive 0x17 TryPlaySound (the
   tree's sound id -> the object file's / global file's SndInfo list (ResFile +0x18, {id, event id}) ->
   PlayBySource(event, stack object or me)), 0x30 TryKillSounds (QuietBySourceID), cXObject delete
   (QuietBySourceID), camera notes, game-mode setters in the state machines (main menu 2, pregame/loading 3,
   CAS 4, live 1 via BGCall_SetGameModeAndResumeSounds, pause/build-buy 6), options (SetOldFXVolume,
   SetMusicVolume, SetAmbientVolume, SetVOXVolume).

## 2. Session 1 results

### What works (evidence: $S/a1/shots/*.log with SIMMY_SOUND_TRACE=1, *.wav dumps, *_spec.png)
- **Flash menu sounds** (UIAUDIOTarget, new): every `audio:NAME` the movies set plays its installed sample
  (main menu MMU_UI_BROWSE/SELECT, CAS_OPEN/BROWSE/CLOSE, pause PAZ_*, catalogue PCT_*, options O2T_*, WXF,
  R2L, CSP, PRG). No "(not installed)" in any run. With the synthetic samples the dump shows each click
  as its tone, centred, at -16 dBFS (wavtones on t4.wav: 374BDCEA 1080 Hz, 0064AC15 1600 Hz, ...).
  HUD sounds (HUD_UI_*_SAMPLE) are installed now; the front end's UI sample bank is preloaded.
- **Game modes and music** (cSoundModeManager): front end 2 (title track; restarted when it ends), loading
  3 (fades music/effects out, the load_loop sample), CAS 4 (music_24_bbcas1..3, 65% volume), live 1 via
  BGCall_SetGameModeAndResumeSounds, pause/build-buy 6 (bbcas). Trace t1/bb1: "game mode 2 -> 3 -> 4",
  "mode 4 music music_24_bbcas3", "game mode 1 -> 6", "mode 6 music music_24_bbcas1"; real data dumps
  show the streams (real1/real2.wav ~ -21 dBFS).
- **Options volumes** go through cSoundPlayer (GC): O2T -> SetOldFXVolume/SetMusicVolume/SetAmbientVolume/
  SetVOXVolume -> BoxX group volumes + EAudio music volume (vol1.log: "volume: music 9", "music 8"; the
  dump's level drops). The PC buses stay at 1 (they were applied twice before: UIAUDIO also scales by
  the option itself).
- **Object/sim sounds**: behaviour primitive 0x17 Play Sound (SndInfo lists), 0x30 Kill Sounds, object
  animation notes (type 5), sim animation notes (type 5) and footsteps (type 1:
  footstep_<floor>_shoe_<step>, floor from the FloorSet kind), cXObject deletion quiets its sounds.
  t4 (toilet, synthetic samples): doors at load, carpet/tile footsteps, toilet_lowerseat, pee start/loop,
  flush, each at the trace's volume and pan; the dump's tones match the trace sequence and pans
  (footsteps/pee pan 404..461 -> -0.14..-0.27 left, toilet centred). See t4_spec.png.
- **Positional audio** per player camera (GC): listeners = _gd.m_players[i].m_cam, summed; behind the
  listener pans > 0x400 (phase-flipped side). Split screen (sp1.log, SIMMY_TWO_PLAYER=1 --split=wide
  headless): runs, sounds play with both listeners ("door_open_barred volume 504 pan 1270").
- **In-game music** (stereo/DJ booth sound events, group 2): cTrack "playhitpatch" -> cGZMusic -> EAudio
  music stream, sequence group 1 fades the previous one (t5: stereo_pop then music_24_djbooth_fast:
  "music stream A90DBD02 stops", "3CE22CBB starts"). Lot 9 has no stereo; tested with SIMMY_SOUND_EVENT.
  With the real data the stream plays (real2.wav, stereo_pop on TV object 130, 30-66 s at ~-20 dBFS).
- **Simlish (VOX, group 3)**: "playvox" picks the voice's hit list from cAudioInfo field 0 (female/male/
  child) and plays (t5: v_sit_dislike, vox_serenadee_acc at pan 625). Data missing (samples).
- With the real data (no samples.arc) the game runs, logs "[audio] samples.arc not found: sound effects
  and voices are silent" once; tracks end instead of waiting for ever.

### Dev aids
- SIMMY_AUDIO_DUMP=<file.wav> (alias of SIMMY_AUDIO_WAV): the final stereo mix.
- SIMMY_SOUND_TRACE=1: "[snd]" lines: ui audio:NAME -> id, queue event, event NAME plays (group,
  source), note NAME: sample/stream id, volume, pan, music stream starts/stops, game mode, volumes, track
  errors.
- SIMMY_SOUND_EVENT="<frames>:<event>[@<source>];...": plays events by name/0xid N frames into live mode
  (source: object id, "sim" = player 1's sim (default), "none").
- a1/py/mksamples.py <root>: synthetic samples.arc (tones encoding the id) + links to the real DATA;
  a1/py/wavtones.py <wav> <log>: finds the tones of the samples the log names (time, level, pan).
  Use DATA=$S/a1/data with hl.sh.

### Not ported (SIMMY_STUB) / deviations
- AmbientScorePlayer, AmbientSoundPlayer, ERAmbientScore (the neighbourhood ambience "score%d"; all
  samples): generated stubs (cBoxX calls them; cBoxX::GetSurroundVol(AmbientScorePlayer*) stubbed).
- QuickDataSoundInfo / NamespaceSelector::GetSoundInfo: the primitive reads the SndInfo lists directly
  (no namespace cache).
- Footsteps: objects on the tile (GetFootSound's ObjectIterator), bare feet (+0x130 states) and heels.
- cAudioInfo: room area (field 0xD -> 100), OutdoorTileRatio; IsChild (service NPCs) = false.
- Rumble notes, particle/effect notes (unchanged stubs).
- PC: cSoundCacheItem gives up (retry -16) when samples.arc is missing or the id is not in the index;
  cSoundPlayer::Update drops queued events whose id the index does not hold.
- Base's sample loader reads a second channel when the resource has room for it (the GC read mono);
  the synthetic samples are written mono-sized so pans behave as on GC.

### Fixes
- cGZSndSys::Update (PC deviation): a loaded sound also plays once its start time has come, not only in
  the update where some load finished (fast PC frames reached Play before event time + 15 ms; Simlish
  waited for another sample's load).
- cBoxX game-mode event (PC deviation): the effects fade-out a load starts is finished (in the loading
  mode) before live mode starts; on fast PC loads its closing "quiet all" (0x14) arrived after the
  ambient score started and stopped it (on GC the loading screen outlasted the fade).
- Ported: ERAmbientSound/ERAmbientScore/EAmbientScoreManager (e_rambientscore.cpp), AmbientScorePlayer
  (25 fns), AmbientSoundPlayer (17 fns), cBoxX::GetSurroundVol(AmbientScorePlayer*) (now static, as on
