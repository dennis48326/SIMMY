## Tools / how to run
- `s10/hl.sh FRAMES NAME "PAD"` headless (card in `$S/s10/run/USA/Card A`), `s10/shot.sh FRAME NAME "PAD"`
  offscreen screenshot (card in `$S/xdg10/SIMMY/USA/Card A`). Fresh card = delete that `USA` dir. Run ONE at a time.
- `s10/res.py FILE [dump TYPE ID out]` lists (or extracts) the host/"both" section resources of a .ngh or .gci.
- `s10/hood.py FILE` decodes NGBH / NBRS (every neighbour) / FAMI / User resources (formats verified: every
  stream of DEFAULT.NGH decodes to its exact end).
- `s10/cmpres.py A B` compares the resources of two files (e.g. default.NGH vs a save).
- `s10/card_saved1/` = a card saved by the new-game script (copy to `.../USA` to test Continue).
- `[hood]` log lines: default/saved neighbourhood summary, the house entered and why.

## Works
- Globs::Startup makes Globs_pNeighborhood (NeighborhoodImpl). New game: GameData::LoadDefaultNeighborhood ->
  NghResFile::ReadFromFile, NeighborhoodImpl::Load (74 neighbours, 22 families, 51 user sims), Save back.
- PreGameCasPlayer1State::Reset: player 1's neighbour (family 1 member 0, GUID 4da247c8 "Chris", id 34)
  InitDefaultValues (random interests), LoadCreateASim -> PrepareSimData (custom char slot 0 = neighbour 34).
- PreGameState: entering CAS sets family 1 flag 0x10 (P1 done CAS) and house -1; continuing skips CAS when
  family 1 has 0x10 (m_needCas = 0).
- CAS Done: SaveSimToFamilySlot -> GameData::ReplaceSimData -> Neighbor::LoadFromCharacter (personality, sign,
  aspiration, skills..., the look into its user ObjSelector's CasSimDescriptionS2C) -> SaveCASDataToNeighborhood
  -> NeighborhoodImpl::Save into the NghResFile -> SimsMemCardWrap::SaveNewGame (Save again) -> card.
- Verified by decoding the card: FAMI 16385 (player family 1) house -1, flags 0x11; neighbour 34's person data
  changed; User 24 (4da247c8) holds the CAS look (body parts, morphs, personality differ from default). All
  other resources byte-identical to DEFAULT.NGH except strings now written as GC does (0xFFFE + big-endian
  UTF-16; DEFAULT.NGH has 0xFEFF little-endian; both read).
- Continue: LoadGameTarget -> LoadSavedNeighborhood -> NeighborhoodImpl::Load from the card cache ->
  PreGameState skips CAS -> PlayerEnterHouse (family 1 house -1 -> start lot 9) -> live mode (cont1.png).
- LiveModeInitState stage 12: SetPlayerFamilyInHouse(house) (family 1 house = 9 after entering live mode);
  SimsMemCardWrap::SaveGame (saves from live mode) sets it too, then saves.

## Data model (include/simmy/classes/neighborhood.hpp)
- NeighborhoodImpl: m_vars[0x24] (+0x84; 1 story flag, 2 house, 4 player1 id, 7 entered house, 0x13 p2, 0x23
  visiting), m_families (FamilyImpl*), m_neighbors (by id-1, null = free id), m_name, m_houseNumber.
- Neighbor (0x1B8): m_pers[0x50] person data (+0x70; [2..7] personality, [0x3D] family number, [0x46] sign...),
  motives, m_guid, m_selector (ObjSelector*), RelMatrixImpl, 20 bookmarks (tree, node kept as index), 7 active.
- FamilyImpl: m_members (GUIDs), m_house (-1 moving in), m_flags (1 phone, 0x10 P1 done CAS...);
  PlayerFamilyImpl (resource id | 0x4000): inventory/goals/clothing unlocks kept as their streamed bytes.
- CAS sims' looks: ObjSelector::m_simDesc on user selectors (ObjectFolderImpl::LoadUserData/SaveUserData,
  'User' = UserDataSaveLoad {GUID, CasSimDescriptionS2C::DoStream}).
- API for the lot agent: `Globs_pNeighborhood->GetFamily(_gd.m_fieldD8)` is the player family (NOT
  GetFamilyInHouse(9): story lots < 13 never return family 1; house 9 also has NPC family 14 "#house09");
  `f->CountMembers()`, `*f->GetIndexedMember(i)` GUIDs, `Globs_pNeighborhood->SimDescriptionOf(guid)` the look,
  `_gd.m_players[0].GetPrimaryNeighbor()` player 1's Neighbor.
