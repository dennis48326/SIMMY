## 1. Survey: what the GC draws that the port skips (ranked by visibility)

1. **Shadows** (e_rlevel.c ERLevel::Draw 80234C98, per room floor). Destination alpha is a stencil:
   sky+terrain keep the clear alpha, everything after writes 0x40; shadow geometry (POLYSHADOW mask:
   unlit black, no z test, geometry mode 0x4000) blends DSTALPHA/INVDSTALPHA and writes alpha 0, so a
   pixel darkens once by 0x40 (25 %). Outside: wall shadow models (EIWallPart::DrawOutsideShadows via
   ERLevel +0x2E2D8), sims' shadow models (ESimShadow, model 0x6EF2F2DA posed by the sim's skeleton)
   and the objects' own models, all flattened along the sun (ELevelDrawData +0x40). Inside rooms: soft
   blobs (GLOBAL_SHADOW_CIRCLE under sims, GLOBAL_SHADOW_SQUARE x1.35 footprint under objects, alpha
   0.35). Then EIFloor::DrawStencil clears the floor's alpha. CAS: CasSimRenderer::DrawShadow
   (DrawShadowWithStencilInverted, slant 0.2). **Ported this session** (see 2).
2. **Interior lighting**: point lights (lamps, EIPointLight/InitBulb), window portal lights
   (EIPortalPointLight, ELightGrid::ConnectPortalLights/EvaluatePortalLight/AddLightsToVertices),
   animated lights, highlights (BlendHighlights). Interiors are ambient + sun only. Large visible
   difference indoors (rooms darker, no lamp pools). Not started (world/lighting heavy: room manager
   areas, vertex grid).
3. **Particles** — two systems, both unported:
   - PSystem ("PART" resources in emitters.arc, ParticleManager `_particleman`; engine/psystem.c,
     game/emitter.c, emitterspr3d.c (sprites / camera-following / geometry / tabbed geometry
     emitters), three level systems g_pParticleSystem, g_pParticleModelSystem (processed per room in
     ERLevel::Draw), g_pParticleWeatherSystem). 845 of 1047 attachment nodes use it: sinks,
     particle_flies (dirty objects), smoke/sparks/fire, fountains, hot tubs, stink bombs, plumb bob
     (PlumbBob::AddParticleSystem), text particles (AptFormat), ghost effect, bone particles
     (EBoneParticle, sim animation events), weather (rain).
   - Effects:: system (effectsemitters/effectsattachments arcs, EffectsManager, FastParticleEmitter
     84 KB raw, REffectsEmitter/Sequencer, GameEffectsManager::PreRender/RenderCB): 202 nodes —
     notably **shower_particles (both nodes)**, stove_smoke, fire_extinguish, slot machine, outhouse.
   - Glue: ObjAnimDef +4 = REffectsAttachment id; EParticleObj::CreateEffects -> EParticleEffect per
     node (type 0 PSystem Emitter*, type 1 Effects::Effect); ISimsObjectModel Update/Draw/anim events
     (4 stubs) and ~ISimsObjectModel; cXObjectImpl::TryParticleEffect (primitive 0x3D).
4. **Weather**: rain (Weather, ApplyWeatherEffects -> InterpolateToGraySky, rain particle system),
   EHouse::UpdateWeather. Only when it rains.
5. **Frame effects** (FrameEffectsManager: MotionBlur, Bloom, DepthOfField; frameeffectsngc.c does EFB
   copies at reduced size + jittered blends). Created by the CameraDirector, switched on only by
   animation events (animeventhandlersupport.c: bloom/blur/DOF notes in social / career / object
   animations) and camera note tracks; DOF also changes ERLevel's foreground list. Rare in normal play.
   EGraphics::SetMotionBlur (CAS stick spin, triggerCameraBlur) ends in ENgcRenderer::ProcessFrameEffects,
   which is **empty (0xC bytes) in the release build** — nothing to port there. Censor blur
   (ESim::CensorOrderTableCallback, shower/toilet use) is a sprite/mosaic order-table record (stub).
6. **Time of day**: InterpolateLevelLighting/sky lights are ported; missing: ELiveMode background colour
   from the sun (ERLevel::GetSunLight), rain greying, ERC::LightsRadiosity (outside radiosity).
7. Smaller: green ghost light, skill meter, cursor highlight (ESim::Draw stubs), SAnimator2 props
   (DrawProps / DrawPropsShadow: props are not ported), reflections (ENgcRenderer reflection texgen
   ReflectionCoord: unused by the UI, used by some shiny shaders — texgen 3 falls back to uv).

## 2. Shadows — what was done

All functions ported from the raw decomp, address headers:

- ERLevel (e_rlevel.cpp): ctor blob DL (unit quad, recorded as EGEVerts; GC used the float-array
  TriStrip, data 803FF460/803FF4A0), dtor frees it; Draw: Stencil(1,0,0)/(0,0,1) around sky+terrain,
  the per-room shadow pass (as 80234C98); DrawSimShadow 80235F58, DrawObjectShadowsOutside 80234508,
  DrawObjectShadowsInside 80234740 (s_softShadowAlpha 0.35, s_shadowScale 1.35 from the ELF),
  ObjectShouldBeOccluded (both overloads), NotifyInstanceMoved, RefreshRoomAssignment,
  SetDrawWallShadowsFunc.
- E3DWindow::TestAsRect 802E5998 (e_3dwindow_cull.cpp).
- EShader::SelectForShadowMask/SetShadowAlpha (no-op on GC), ENgcShader::SelectForShadowMask 8034DD3C,
  ERModel::DrawShadow / DrawShadowWithStencilInverted.
- EIStaticModel::DrawAsShadow 8022CC24 / DrawShadow 8022CE1C (shader slot tagged |1 as on GC);
  EInstance::CalcShadowLight(+Weighted), ShadowDirAtPoint, TruncateLightDirection, GetShadowCenter.
- ESim: shadow creation in the ctor (0x6EF2F2DA, owner = sim, anim = sim's controller), dtor,
  UpdateShadow 80034B14, GetShadow; ESimShadow (ctor/dtor/DrawShadow/GetShadowCenter = pelvis bone).
- EGlobal::AllocPersonInstance: shadow inserted listed (0x40000), ThisSide/Hidden on sim and shadow.
- ThisSide/Hidden (8004E710/8004E794) and ISimsObjectModel::CreateShadow/GetShadow; EIObjectMan::AddObject
  sets ThisSide/Hidden (OtherSide + window portal lights still stubbed).
  **PC deviation**: the callbacks' data is the object's id (cXObjectImpl::GetObjectFromID) — the GC
  stored the cXObject pointer, which does not fit EInstance's 32-bit data slots on x64.
- EIWallPart::DrawShadow 8002B504 and DrawOutsideShadows 8002B68C; EHouse ctor installs the callback.
- EIFloor::DrawStencil 800474AC / DrawShadow 800475A4; FloorRoom now maps to the room's lighting group
  like the GC (80047738) so floors, walls, objects and sims agree on the level's room index.
- SAnimator2::positionCharacter: the shadow's bounds (3x the sim's sphere).
- CasSimRenderer::DrawShadow 8016F304.
- **Bug fix (renderer)**: ENgcRenderer::InitGX set GX_PF_RGB8_Z24; the GC sets RGBA6_Z24 (1) unless AA.
  Without destination alpha aurora maps DSTALPHA to ONE, so shadows came out solid black and the Apt
  stencil (masks) never worked as designed.

Works: outside sim shadows (follow the pose), object shadows (trees, bin, mailbox, fences, furniture
projected onto the lawn/patio), wall shadows outside, inside object blobs (verified drawn; they sit
mostly under the object and are faint — as the GC), CAS shadow path. Scales with the EFB (geometry, no
copies), MSAA fine.

Left / known:
- Sims inside rooms get no shadow: the person's room (data 0x1D) is never written by the port
  (cXObjectImpl::SetLocation's ResolveRoomID 800DF228 part and cXPersonImpl moves are not ported;
  objectplace.cpp / person.cpp, world/sim agents). Once data 0x1D is maintained, inside sims get the
  blob automatically.
- Props (DrawPropsShadow: props not ported), pets' shadow models, EInstance::ShadowDirAtPointWeighted
  (light grid weights), OtherSide for portals.
